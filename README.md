# bond_what_web_app
Prototipo funcional web de Bond What.

## Estructura del Prototipo

El prototipo se divide en dos grandes bloques de navegación:

### 1. Zona Externa (Landing & Accesos)
Páginas de presentación y acceso inicial orientadas al usuario nuevo:
* `index.html`, `aprender.html`, `nosotros.html`, `tienda.html`, `ingresa.html`, `registro.html`.

### 2. Zona Interna / Core de la Aplicación (Web App)
El CORE de la webapp. **Recomiendo especialmente explorar las siguientes secciones clave por su nivel de desarrollo:**
* **`web_app_laboratorio.html`**: TAREA: Crea un nuevo MOC, "vincula tu teléfono" e itera tu modelo hasta finalizar el moc.
* **`web_app_arena_practica.html`**: TAREA: Navega por la sección de duelos, vincula tu teléfono y juega un duelo.
* *Otras vistas de soporte:* web_app_inicio.html, web_app_biblioteca.html, web_app_comunidad.html, web_app_mi_progreso.html, web_app_perfil.html, web_app_mapa_islas.html
